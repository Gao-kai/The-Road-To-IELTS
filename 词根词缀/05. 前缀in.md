# 前缀in和inter

前缀in在英文里面常用于表达下面两个意思：

1. 和ex相反，它表达的是在里面，向里的意思。
2. 表达否定，反对的意思

## in表达里面的含义

| 单词        | 释义                         | 助记                                                                              | 拓展                                                                            | 例句                                               |
| ----------- | ---------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | -------------------------------------------------- |

| indoor      | adj 室内的                   |                                                                                   | outdoor adj 室外的                                                              | No smoking in any indoor facilities.               |
| facility    | n 场所，设施                 |                                                                                   | indoor faciliies 室内场所                                                       | An indoor swimming pool 室内泳池                   |
| investigate | v 调查，侦查                 | vestige 表示痕迹的意思<br />在in里面找痕迹就是调查、侦查的意思<br />ate是动词后缀 | investigate the accident<br />investigation n 调查<br />research n 科学研究调查 |                                                    |
| invite      | v 邀请                       | invite sb to do sth 邀请某人做某事                                                | 邀请invite发明家inventor来搞发明invent                                          | They have invited me to go to the Paris with them. |

| inventor    | n 发明家                     |                                                                                   |                                                                                 |                                                    |

## in表达否定的含义

| 单词      | 释义                   | 拓展                                             | 例句                                         |
| --------- | ---------------------- | ------------------------------------------------ | -------------------------------------------- |
| incorrect | adj 不对的             | incorrect information 错误信息                   |                                              |
| informal  | adj 不正式的，非正式的 | formal adj 正式的<br />casual adj 随意的，偶然的 | The house has an informal atmosphere         |
| inactive  | adj 不活跃的，无作用的 | active adj 活跃的                                | Some animals are inactive during the daytime |
