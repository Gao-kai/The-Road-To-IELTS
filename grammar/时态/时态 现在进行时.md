# 现在进行时

## 场景

现在进行时态一般用于表达以下几种场景：

1. 表达说话时正在发生的事情（最常用）
2. 表达最近一段时间内一直发生的动作但是说话时未必正在发生的动作
3. 表达说话者的某种情绪（多伴随always这类频率副词）
4. 表达将要发生的动作（多用于位置转移类动词 coming\leaving\arriving\dying）

```bash
I am reading now.
He is studying english these days. 最近一直在学习 但是说话时未必正在学习英语
I am coming.
```

现在进行时的常见标志词有：

- Look!
- Listen!
- now
- at present
- at this moment
- these days

## 现在进行时的结构

核心语法结构为：

```bash
主语 + be动词 + 现在分词ing
```

这里的be动词需要根据主语和语境来综合判断，现在分词就是动词的ing形式，其变化规则为：

1. 直接在动词后加ing，比如read -> reading
2. 如果动词以不发音的e结尾，去掉e然后加ing，比如leave -> leaving
3. 对于重读闭音节词，双写末尾字母再加ing，比如sit -> sitting
4. 以ie结尾的单词，先将ie替换为y，再加ing，比如die -> dying

```bash
Everyone wants to reach the top of the mountain,but all the happiness happens while you are climbing it.
```
