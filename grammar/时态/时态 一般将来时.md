# 一般将来时

## 时间标志词

1. tomorrow
2. next + 时间
   - next week
   - next month
   - next year
3. in + 时间段（几天内）
   - in a week
   - in a month
   - in a year

## 一般将来时的肯定句

1. 主语 + will/shall（not） + 动词原形
   - 多用个主观意愿想要做的事情
   - 多用于主语临时决定要做的事情
   - will和shall都是助动词，后面只加动词原形
   - will表示第一第二第三人称都可以
   - shall只可表示第一人称

2. 主语 + be（not） + going to + 动词原型
   - 多用于经过考虑后要做的事情
   - 多用于提前计划好要做的事情
   - 多用于根据客观迹象推测马上要发生的事情（下雨）

```bash
I will go to the school tomorrow morning
I am going to watch a movie with my friends this weekend
```

1. 根据客观迹象推测马上要发生的事情（将会有）
   - There will be + 动词原型
   - There + be going to + 动词原型

## 一般将来时的疑问句和特殊疑问句

1. Will/Shall + 主语 + 动词原型？（多用于征求对方意见）
2. Am/Is/Are + 主语 + going to + 动词原型？
3. 特殊疑问词 + will/shall + 主语 + 动词原型？
4. 特殊疑问词 + Am/Is/Are + 主语 + going to + 动词原型？

```bash
I will arrive in Beijing tomorrow morning.

# 一般疑问句
Will you arrive in Beijing tomorrow morning?

# 特殊疑问句（动词一定在主语前面）
When will you arrive in Beijing?
Where are you going to arrive tomorrow morning?

```
