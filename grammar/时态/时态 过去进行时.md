# 过去进行时

在日常生活中，我们如何表达**过去某个时刻你正在做什么**这个意思呢？
答案就是使用过去进行时，过去进行时一般用在：

1. 表达过去某一时刻正在进行的动作（最常用）
2. 表达过去某段时间内持续发生的事情

```bash
I was watching NBA TV at 7:00 pm yesterday evening.
```

## 语法结构

过去进行时最常见的语法结构为：

```bash
肯定句：主语 + was/were+现在分词doing
否定句：主语 + was/were+not doing
一般疑问句： Was/Were + 主语 + doing
特殊疑问句：特殊疑问词 + was/were + 主语 + doing
```

⚠️ 注意：这里的was和were都是助动词 用于构成时态，不是系动词

## 标志词

过去进行时经常见的标识词有：

1. at + 具体某一刻 + 过去时间
   - at 7:00 am yesterday morning
   - at 8:00 pm last weekend evening
   - at two o'clock last night
2. this time + 过去时间（表达过去的这一刻）
   - this time yesterday
   - this time last week
   - this time last month
   - this time last year
   - this time last night
3. 在when、while、as引导的时间状语从句中，表示某人过去做某事的时候
